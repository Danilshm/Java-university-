# Aggregation 
- Агрегация — это слабая связь между объектами. Один объект содержит ссылку на другой, но они могут существовать независимо друг от друга. Если главный объект удаляется, подчиненный объект продолжает жить.
- **Связь:** «Слабое владеет» (_weak ownership_).
- **Пример из жизни:** Университет и Студенты. Если университет закроется, студенты не исчезнут — они перейдут в другой вуз.
``` 
class Student {
    String name;
    public Student(String name) { this.name = name; }
}

class University {
    private List<Student> students; // Студенты передаются извне

    public University(List<Student> students) {
        this.students = students;
    }
}

```
# Composition
 - Композиция — это сильная связь между объектами. Вложенный объект является частью главного объекта, и его жизненный цикл полностью зависит от владельца. Если главный объект уничтожается, подчиненный объект тоже уничтожается.
- **Связь:** «Строгое владеет» (_strong ownership / part-of_).
- **Пример из жизни:** Человек и Сердце (или Дом и Комнаты). У человека не может быть сердца, которое существовало отдельно до него или продолжит жить после его гибели.
- **Пример кода:**
```
class Heart {
    public void beat() { System.console().printf("Thump"); }
}
class Person {
    private final Heart heart; // Создается внутри владельца

    public Person() {
        this.heart = new Heart(); // Уничтожится вместе с Person
    }
}
```
