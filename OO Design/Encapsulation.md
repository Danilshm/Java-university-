# Encapsulation
- принцип объектно-ориентированного программирования (ООП), который объединяет данные (поля) и код (методы) в одном классе и скрывает внутреннее устройство объекта от внешнего мира.
### Главные цели инкапсуляции
- **Объединение:** Переменные и методы хранятся вместе внутри класса.
- **Сокрытие данных:** Защита полей от прямого изменения из других классов.

- **Сокрытие реализации:** Пользователь объекта получает простой интерфейс (методы), а сложная логика остается внутри
### Как реализовать инкапсуляцию
- Объявить поля класса с модификатором `private`, чтобы к ним нельзя было обратиться напрямую извне.
- Создать публичные (`public`) методы — **геттеры** (`getter`) для чтения значений и **сеттеры** (`setter`) для записи значений.
- Добавить в сеттеры или методы бизнес-логики проверки, которые исключают появление неверных данных (например, отрицательный возраст или баланс)
```
public class Person {
    private String name; // поле скрыто
    private int age;     // поле скрыто

    // Геттер для имени
    public String getName() {
        return name;
    }

    // Сеттер для имени с проверкой
    public void setName(String name) {
        if (name != null && !name.trim().isEmpty()) {
            this.name = name;
        }
    }

    // Геттер для возраста
    public int getAge() {
        return age;
    }

    // Сеттер для возраста с проверкой
    public void setAge(int age) {
        if (age >= 0 && age <= 120) {
            this.age = age;
        }
    }
}
```
