# Static 
- Статическое связывание происходит во время компиляции. Компилятор точно знает, какой именно метод или переменную нужно вызвать, основываясь на типе ссылки.
- **Что относится:**
    - `private`, `static` и `final` методы.
    - Перегруженные (overloaded) методы.
    - Поля (переменные) класса — они не полиморфны в Java.
- **Особенности:**
    - Работает быстро, так как выбор метода происходит до запуска программы.
    - Если метод помечен как `static`, он принадлежит самому классу, а не конкретному объекту.
# Dynamic 
- Динамическое связывание происходит во время работы программы (runtime). Какой именно метод вызовется, определяется не типом ссылки, а типом фактического объекта, на который эта ссылка указывает.
- **Что относится:**
    - Обычные переопределенные (overridden) методы экземпляра. 
- **Особенности:**
    - Обеспечивает работу динамического полиморфизма.
    - Позволяет переменной базового класса ссылаться на объект дочернего класса и вызывать переопределенный метод этого дочернего класса
# Static and Dynamic code 
```
class Animal {
    // Статический метод
    public static void classInfo() {
        System.out.println("Это класс Animal");
    }

    // Динамический метод
    public void makeSound() {
        System.out.println("Животное издает звук");
    }
}

class Dog extends Animal {
    // Скрываем статический метод родителя (это НЕ переопределение)
    public static void classInfo() {
        System.out.println("Это класс Dog");
    }

    // Переопределяем динамический метод
    @Override
    public void makeSound() {
        System.out.println("Гав-гав!");
    }
}

public class Main {
    public static void main(String[] args) {
        // Создаем ссылку типа Animal, но объект внутри — Dog
        Animal myPet = new Dog();

        // 1. СТАТИКА (Раннее связывание):
        // Компилятор смотрит ТОЛЬКО на тип ссылки (Animal).
        myPet.classInfo(); // Выведет: "Это класс Animal" (хотя внутри сидит собака!)

        // 2. ДИНАМИКА (Позднее связывание):
        // Java во время работы программы смотрит на реальный объект (Dog).
        myPet.makeSound(); // Выведет: "Гав-гав!"
    }
}
```
