# Supervised
## Definition: 
- The model trains on labeled data, where each input comes with a known correct output. The algorithm learns a mapping function to predict outcomes for new, unseen data.
## Main Tasks:
- Classification: Assigns data into discrete categories (e.g., spam vs. non-spam emails, disease diagnosis).
- Regression: Predicts continuous numerical values (e.g., house prices, sales forecasts).
## Common Algorithms: 
- Linear regression, logistic regression, support vector machines (SVM), decision trees, and random forests.
## Pros & Cons: 
- Offers high accuracy and clear performance metrics, but requires expensive and time-consuming manual data labeling.
# Unsupervised
## Definition: 
- The model works with unlabeled data, exploring raw information independently to find hidden structures, clusters, or relationships.
## Main Tasks:
-  Clustering: Groups similar data points together (e.g., customer segmentation).
- Association: Finds rules that describe large portions of data (e.g., market basket analysis).
- Dimensionality Reduction: Simplifies data while preserving key features (e.g., Principal Component Analysis).
## Common Algorithms:
- K-means clustering, hierarchical clustering, and Principal Component Analysis (PCA).
## Pros & Cons: 
- Utilizes abundant raw data without needing human-annotated labels, but results are harder to evaluate and require expert interpretation.
