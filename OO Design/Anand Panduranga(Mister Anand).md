## Structure of OO programming
1) Classes ( blueprint of objects)
2) Objects(instances of a class)
3) Methods(Describe the behavior of the object and functions inside a class)
4) Attributes(Data stored in the object's fields)
## Principles of OOP
1) Encapsulation: Bundling data and methods to restrict access/
2) Abstraction: Hiding unnecessary details
3) Inheritance: Sharing characteristics between classes 
4) Polymorphism: Multiple forms of a single method

## Structured programming
- Sequence – a set of statements that run in a linear order
- Selection – allows different paths through a program
- Iteration – allows a block of code to be repeated
## For loop
for (initialisation; condition; update)
{
  statements
}
- Initialisation is executed once when the loop first runs.
- The loop will continue to iterate whilst the condition is true. It is checked at the start of each iteration.
- The update (typically increment or decrement) will occur after each iteration through the loop, i.e. after all statements within the loop.
