# Constructor 
- Конструктор в Java — это специальный метод, который автоматически вызывается при создании нового объекта и задает его начальное состояние
## Главные особенности
- Имя: 
	- Всегда совпадает с именем класса (и начинается с большой буквы).
- Возвращаемое значение: 
	- У конструктора нет типа возвращаемого значения (даже void).
- Вызов: 
	- Запускается только один раз при создании объекта с помощью ключевого слова
## Зачем он нужен?
- Инициализация:
	- Задает начальные значения полей объекта.
- Безопасность: 
	- Гарантирует, что объект не создастся без важных данных.
```
 public class Car {
    String model;
    int maxSpeed;

    // Конструктор с параметрами
    public Car(String model, int maxSpeed) {
        this.model = model;
        this.maxSpeed = maxSpeed;
    }
}
```
