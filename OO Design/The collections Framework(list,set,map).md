# List, set, map
- Why use it?
	- Reusable structures and useful orepations - less code to write.
## List
- Order matters
- Duplicates are allowed
- Access by position 
- Example:
	- ["Math", "Java", "Math"]
- Java example
```
List<String> modules = new ArrayList<>();
modules.add("Math");
modules.add("java");
```
- Use a list when you need order, positions, or repeated values.
