- Полиморфизм в Java — это способность программы использовать объекты с одинаковым интерфейсом или общим родительским классом без информации об их конкретном типе, при этом поведение кода меняется в зависимости от фактического объекта.
## Виды полиморфизма в Java
- Статический (время компиляции / Overloading):
	- Реализуется через перегрузку методов.
	- Несколько методов в одном классе имеют одинаковое имя, но разные параметры (количество или типы).
	- Выбор метода происходит на этапе компиляции (раннее связывание).
- Динамический (время выполнения / Overriding): [[Abstraction, Inheritance and Interfaces#Overriding methods|Overriding]]
- Реализуется через переопределение методов и механизм наследования/интерфейсов.
	- Дочерний класс меняет реализацию метода родителя.
	- Выбор конкретного метода происходит во время работы программы (позднее связывание) по фактическому типу объекта.
